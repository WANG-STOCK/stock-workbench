# 技术面股票工作台（Stock Workbench）

一个**零依赖、纯本地**的 A 股技术面交易工作台：自选盯盘、K 线与技术指标、
买卖持有信号、选股扫描、价格预警，全部在浏览器里完成。

- 后端：Python 标准库（`http.server`），无需 `pip install`
- 前端：原生 HTML/Canvas，无 CDN、无第三方库，断网也能看图
- 数据源：**通达信本地优先** → 在线兜底（新浪 K 线 + 腾讯实时/搜索）

## 运行

```bash
# 方式一：直接运行
python server.py
# 方式二：Windows 双击 start.bat

# 然后浏览器打开
http://127.0.0.1:8723
```

默认端口 8723，可用环境变量改端口：`PORT=9000 python server.py`

## 功能

1. **自选 / 盯盘**：左侧自选列表，每 5 秒轮询实时行情（价、涨跌幅、信号点）；
   点「加当前」把当前股票加入自选，点「刷信号」重算技术面评级。
2. **K 线与指标**：蜡烛图 + MA5/10/20/60 + 成交量；子图可切换
   MACD / KDJ / RSI；主图可叠加 BOLL。支持 5 分 / 15 分 / 30 分 / 60 分 / 日 / 周。
   鼠标悬停显示 OHLC 与指标数值。
3. **买卖持有信号**：基于趋势 / 均线排列 / MACD 金叉死叉 / KDJ 超买超卖 /
   RSI / BOLL / 量能 的复合打分（-100~100），给出「强烈买入 / 买入 / 持有 /
   减仓 / 卖出」建议与逐条理由。
4. **选股扫描**：按「自选列表 / 自定义股票池 / 通达信全市场」三种范围，
   对每支股票跑信号引擎，按评分排序输出候选。内置 7 种策略：
   - `综合评分`（买入及以上）、`均线多头排列`、`MACD/KDJ 金叉`、
     `突破 20 日新高`、`放量上涨`、`缩量企稳反弹`、`均线粘合突破`。
5. **价格预警**：对当前股票设置「涨破 / 跌破」某价，每 6 秒检测，触发时弹提示。

## 操作建议与仓位（买多少 / 卖多少）

信号面板会直接给出**可执行建议**，而不仅是评级：
- 目标仓位 %、目标股数、本次操作（买/卖 N 股）、涉及金额。
- 规则：强烈买入→打满单票上限（默认 25%）；买入→60%；持有→维持；
  减仓→砍半；卖出→清仓。受「一手=100 股、股价、资金」约束，资金不足会提示。
- 左上角输入**资金**与**持仓股数**即可即时重算（打开持仓股时自动填入台账数）。

## 我的持仓（持仓台账）

侧栏「我的持仓」可记录每只股票的代码 / 股数 / 成本，工作台据此驱动
「买多少 / 卖多少」，并展示浮动盈亏。数据存于 `data/positions.json`。
**这是本地台账，不是券商真实持仓**——详见下方「券商对接」。

## 评分权重自定义

侧栏「评分权重」提供 7 大类（趋势 / 均线 / MACD / KDJ / RSI / BOLL / 量能）
滑块（0~2 倍），保存后下次计算即生效；「重置」恢复默认。权重存于
`data/config.json` 的 `weight_multipliers`。

## 券商对接（边界说明，很重要）

- **当前券商连接器未连接**，且公开连接器主要提供行情/自选数据，
  **不暴露下单通道**。因此本工作台**不会自动下单**，也不会擅自读取你的真实账户。
- 它把技术面信号算成一份结构化「委托单意图」（`core/broker.py`
  的 `format_order_ticket` / `humanize`），由你在**券商 App / 连接器授权后**执行。
- 若你已在 WorkBuddy「连接器中心」连接并授权券商/通达信账户，且有持仓与委托接口，
  可由智能体侧把真实持仓写回 `data/positions.json`（已实现 CRUD），
  并把委托单通过连接器提交——这属于需要你**明确授权**的外部动作。
- 想要「打开工作台就知道买/卖/持有哪个、多少」：把持仓记进台账 + 开启
  「盘中盯盘提醒」自动化即可，它每个交易日 9:30–15:00 每 15 分钟扫描并 push 提醒。

## 云端长期运行（24/7 盯盘）

详见 **`deploy-cloud.md`**。要点：
- 后端是零依赖 Python，用 Docker / 裸 Python 跑在任意云主机即可：`docker compose up -d`。
- 前端「评分权重」面板里填「云端后端地址」= `http://<公网IP>:8723`，即可远程盯盘。
- 把 `data/config.json` 的 `cloud_url` 设为云地址后，「盘中盯盘提醒」自动化会改访问
  云端后端，**本机不开也能持续推送买卖提醒**。
- 安全：后端无鉴权，公网务必限 IP / 加反代密码；不要裸奔 8723。

## 配置通达信（可选，推荐）

编辑 `data/config.json`，填入你本机通达信的 `vipdoc` 目录：

```json
{ "tdx_path": "D:/通达信/vipdoc" }
```

配置后：
- 日线 / 周线优先读本地 `.day` 文件（更快、不受限），选股「通达信全市场」
  会扫描 `vipdoc/sh/lday`、`vipdoc/sz/lday` 下全部 A 股。
- 分钟线与实时行情仍走在线接口。

不选通达信时，所有数据走在线接口（新浪 + 腾讯），功能完全一致。

## 自定义股票池

编辑 `data/universe.txt`，每行一个代码（带市场前缀，如 `sh600519`），
选股时选「自定义股票池」即扫描这些标的。

## 数据接口说明（实现细节）

| 用途 | 接口 |
|------|------|
| K 线（日/周/分钟） | 新浪 `money.finance.sina.com.cn/.../getKLineData`（scale: 5/15/30/60/240/1200） |
| 实时行情 | 腾讯 `qt.gtimg.cn/q=code` |
| 股票搜索 | 腾讯 `smartbox.gtimg.cn/s3` |
| 通达信本地 | 解析 `vipdoc/*/lday/*.day`（32 字节/条） |
