⚡ 盘中实时建议 · 使用说明

这是分时级别的瞬时买卖提醒，专门解决原来"日K综合评分"在盘中来不及的问题——比如一波拉升到 6 个点又跌回 4 个点，该不该卖，系统会盯住分时帮你即时判断。

面板在哪里

  • 首页顶部新增一个橙色"⚡ 盘中实时建议"面板，每 5 秒自动刷新（带脉动圆点）。
  • 每只持仓卡片底部也有一行内联分时建议，随时可见。
  • 遇到"立即卖出"等强卖场景，该行会红色闪烁警示，不会让你错过。

颜色与动作含义

  • 立即 / 5分钟内止盈 红字 + 可能闪烁 → 该卖了，别犹豫
  • 持有观察 蓝字 → 暂时不急，再看几根
  • 低吸加仓 绿字 → 可以买一点

日内最高 +7.17%，现价 +3.20%，已回落 3.97%。

原因：缩量（量比 0.48）上攻乏力，但 MACD 仍扩张、未破位，所以先不急着卖，再看一根。

下一步：王总您来点一下推送

  1. 打开 GitHub Desktop（桌面图标，或开始菜单搜 GitHub Desktop）。
  2. 左上会显示 stock-workbench 仓库，并提示有若干 commits 待推送（"ahead"）。
  3. 点右上角蓝色 Push origin 按钮（之前已配好代理 127.0.0.1:2334，应能正常连）。
  4. 等进度条走完（几秒到 1 分钟）。
  5. Render 会自动重新部署（约 1–2 分钟），完成后在网站按 Ctrl+Shift+R 硬刷新即可看到新面板。
